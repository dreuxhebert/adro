# Adro

Adro is an experimental AI-powered code editor currently in early development.

The goal of Adro is to explore a different approach to AI-assisted software development: making powerful AI coding tools more accessible through an ad-supported credit system.

Instead of requiring every user to maintain a paid subscription for AI usage, Adro is being designed around a system where users can optionally engage with advertisements to earn credits that can be used toward AI features.

> **Adro is currently under active development and is not yet ready for general use.**

## Vision

AI coding tools can be extremely useful, but access to more capable models and higher usage limits often requires recurring subscriptions.

Adro is being built around a different model:

**Ads → Credits → AI Usage**

The long-term goal is to allow developers to choose how they access AI features. Users may be able to earn AI credits through advertisements while other options, such as paid plans or purchased credits, may be introduced as the project develops.

The advertising system is intended to supplement the development experience rather than interfere with the editor itself.

## Current Status

Adro is in the very early stages of development.

The current version is primarily focused on establishing the core desktop IDE and development environment.

Current work includes:

- Building and customizing the core editor
- Establishing Adro's own branding and interface
- Testing the desktop development environment
- Designing the architecture for AI-assisted coding features
- Planning the AI credit system
- Exploring how optional advertising can fund AI usage

Many planned features described in this README do not exist yet and may change significantly as development continues.

## Planned Direction

Adro is intended to eventually include features such as:

- AI coding assistant
- Context-aware code generation and editing
- AI chat integrated with the development environment
- Project and codebase understanding
- AI usage credits
- Optional advertisements that reward users with AI credits
- Account and credit management
- Multiple AI model options
- Traditional IDE features for editing, debugging, source control, and terminals

The exact feature set and implementation are still being designed.

## Development

Adro is currently being developed and tested primarily on Windows.

The project is not yet packaged as a normal end-user application. At this stage, development builds are run directly from source.

More detailed build instructions and contributor documentation will be added as the project becomes more stable.

## Project Goals

The main goals of Adro are:

1. Build a capable modern development environment.
2. Integrate useful AI assistance directly into the coding workflow.
3. Reduce the cost barrier associated with frequent AI usage.
4. Give users the option to exchange attention for AI credits instead of requiring payment.
5. Keep advertisements separate from and minimally disruptive to the actual coding experience.
